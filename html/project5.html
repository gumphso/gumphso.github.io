Project: Hexlock (Bevy)

Hexlock

Ranked 29th place of of 40 entries for the Wheel Jam 2 gamejam.
Main Artist and Co-Developer: Kira Ash Stephenson

Download on Itch.io
A game designed and developed using raw Rust within the Bevy game engine as a team. Designed and built a 2D game in Rust using the Bevy engine with a friend for the Wheeljam 2 game jam, building the lock-picking mechanic from scratch as no official jam template existed for Bevy. We collaborated under a week-long timeline to scope, implement, and ship a playable submission from concept to release, sharpening rapid-prototyping and scope-management skills under time pressure.
